# Job: AI Engineer / Automation

Example job for this assessment, not a verified employer vacancy.
Purpose: build useful AI tools and reliable business automation in Python.
Total available points: 100. Review work described in the CV, not demographics.

| Requirement | Points | Evidence to look for |
| --- | ---: | --- |
| Build AI tools or automated workflows | 30 | A delivered workflow, its steps, the applicant's contribution and result |
| Build Python services with FastAPI | 20 | A working Python service with requests, validation and useful errors |
| Answer questions using documents and source quotes | 20 | Document search and answers linked to supporting passages |
| Design databases with separate customer access | 15 | Stored business data and checks keeping each customer's records separate |
| Test and release working software | 15 | Automated checks, deployment and handling failures after release |

## How to award points

- MET: direct evidence covers the requirement; award its full points.
- PARTIALLY_MET: related work or only part of the requirement is demonstrated;
  award half its points. Explain what evidence is missing.
- NOT_FOUND: no supporting evidence; award zero. This does not prove lack of skill.
- Every positive award needs an exact quote from the cleaned CV.
- A tool name in a skills list alone is at most partial evidence.
- Add the five awards for the total; retain half points without rounding.
- Example summary bands: 75 or above = strong match; 50 to below 75 = possible
  match; below 50 = weak match. These are provisional, not hiring decisions.
- Ignore name, contact details, age, graduation year and other demographic details.
- A recruiter reviews the evidence and makes the final decision.
