# Fictional CVs

All names, employers and achievements in these six short CVs are invented for
testing. They are not real applicants or a representative hiring dataset.

| File | Purpose |
| --- | --- |
| 01_strong.txt | Evidence across all five job requirements |
| 02_python.docx | Python work, including evidence in a Word table |
| 03_documents.pdf | Document search with source quotes; two pages |
| 04_career_change.txt | Relevant transferable work with Unicode text |
| 05_claims_only.docx | Tool names with little supporting project evidence |
| 06_instructions.pdf | Misleading instructions mixed with a small real claim |

Day 1 preserves the instructions in sample 06 as text. Detecting or resisting
them belongs to later days; extraction itself is not a security check.
Each file represents a different fictional candidate. Scores remain for manual
review against rubrics/rubric.md. The tiny CVs only check the reading path.
